# LOVE NAGOYA 2026

러브나고야! 페스 비공식 한국어 여행 가이드.

16개 업체, 대상 지점 지도, 캐릭터 및 공식 상품 이미지, 스탬프 체크.

HTML/CSS/JavaScript 정적 사이트로 GitHub Pages의 main / 루트에서 배포합니다.

스탬프 체크는 브라우저 localStorage에만 저장되며 기기 간 동기화되지 않습니다. 이미지들은 공식 사이트 URL을 참조하며 각 권리자에게 권리가 있습니다.
